# 연령대 × 연애 상태별 사용자 페르소나

## 개요
HelloBot 운세/타로 콘텐츠 추천 시스템의 사용자를 연령대와 연애 상태별로 세분화한 페르소나 분석입니다. 사용자 프로필 데이터 모델과 콘텐츠 메타데이터를 기반으로 작성되었습니다.

## 적합도 표시 설명
- **✅ 전형적**: 해당 연령대에 일반적이고 자연스러운 상태
- **⚠️ 비전형적**: 해당 연령대에 드물거나 특별 관리가 필요한 상태

## 활용 방안

### 1. 타겟팅 전략
- 연령대와 연애 상태를 교차하여 정밀 타겟팅
- 비전형적 카테고리는 특별 프로모션 또는 제외 고려
- 전형적 카테고리에 마케팅 리소스 집중

### 2. 콘텐츠 추천 알고리즘
- 각 페르소나의 관심사 비중을 가중치로 활용
- 연령대별 선호 콘텐츠 타입(타로/사주) 반영
- 구매력에 따른 가격대 설정

### 3. UI/UX 최적화
- 20대: 모바일 최적화, 빠른 결과, 시각적 요소
- 30-40대: 심층 분석, 상세 설명, 프리미엄 느낌
- 45세+: 전통적 디자인, 큰 글씨, 간단한 네비게이션

### 4. 마케팅 메시지
- 20대 초반: "첫사랑", "짝사랑", "썸타는 상대"
- 20대 중반: "커리어와 사랑", "결혼 vs 일"
- 25-34세: "결혼 타이밍", "인생 동반자"
- 35-44세: "가족 행복", "자녀 미래", "재테크"
- 45세+: "인생 총정리", "건강과 장수", "가문의 영광"

## 매출 데이터 기반 수익 최적화 분석

### 고매출 콘텐츠 카테고리
1. **신년운세** - 모든 세그먼트가 구매하는 필수 콘텐츠
2. **솔로 콘텐츠** - 새로운 인연 탐색 관련
3. **결혼/궁합 콘텐츠** - 관계 검증 및 결혼 결정
4. **이별/재회 콘텐츠** - 감정적 위기 관리

### 수익 최적화 TOP 5 세그먼트

#### 1. 결혼 준비 세대
- **통합 대상**: 25-34세 커플 + 20대 중반 커플 + 썸 단계
- **핵심 매출원**: 결혼/궁합 콘텐츠 (70-80% 관심)
- **구매력**: 34,000-68,000원
- **구매 빈도**: 월 3-5회 (결혼 결정 기간)
- **연간 예상 매출**: 50-80만원/인

#### 2. 싱글 밀레니얼 (25-34세)
- **통합 대상**: 25-34세 솔로 + 20대 중반 솔로
- **핵심 매출원**: 솔로 콘텐츠(70%) + 결혼운(50-60%)
- **구매력**: 30,000-50,000원
- **특징**: 결혼 압박으로 인한 높은 구매 의욕
- **연간 예상 매출**: 36-60만원/인

#### 3. 이별 고민족 (전연령)
- **통합 대상**: 모든 연령대 이별 후 솔로
- **핵심 매출원**: 이별/재회 콘텐츠(30-60%) + 솔로 콘텐츠(40-60%)
- **구매력**: 25,000-70,000원 (연령별 차이)
- **특징**: 감정적 위기로 인한 충동 구매 (월 3-6회)
- **연간 예상 매출**: 40-90만원/인

#### 4. 프리미엄 부부 (35-44세)
- **대상**: 35-44세 부부 (전체의 16.25%)
- **핵심 매출원**: 신년운세 + 부부 궁합 + 위기 관리(45%)
- **구매력**: 68,000-136,000원 (최고 단가)
- **특징**: 정기 구매, 사주 90% 선호
- **연간 예상 매출**: 96-144만원/인 (최고 수익)

#### 5. 청춘 솔로 (20대 초반)
- **통합 대상**: 20대 초반 솔로(35%) + 짝사랑(25%)
- **핵심 매출원**: 솔로 콘텐츠(80-90%)
- **구매력**: 8,000-15,000원 (낮지만 고빈도)
- **특징**: 월 4-8회 구매, 최대 사용자층
- **연간 예상 매출**: 38-72만원/인

## 실제 사용 패턴 기반 핵심 세그먼트 재정의

### HelloBot 핵심 타겟 세그먼트 (사용 빈도 및 니즈 기반)

#### 1. 새로운 인연 탐색자 (New Connection Seekers)
- **정의**: 현재 솔로이며 새로운 연애를 원하는 모든 연령대
- **규모**: 전체의 약 20-25%
- **핵심 질문**:
  - "내 다음 인연은 누구일까?"
  - "언제 만날까?"
  - "어떤 사람이 내 운명의 상대일까?"
- **행동 패턴**: 월 2-4회 정기 방문
- **추천 콘텐츠**: 인연 만남 시기, 이상형 특징, 월별 연애운

#### 2. 짝사랑 고민자 (Crush Anxiety)
- **정의**: 특정인을 좋아하지만 관계 진전이 없는 상태
- **규모**: 전체의 약 10-15%
- **핵심 질문**:
  - "그 사람은 나를 어떻게 생각할까?"
  - "고백해도 될까?"
- **행동 패턴**: **매우 높은 방문 빈도** (주 2-3회)
- **추천 콘텐츠**: 상대방 마음 읽기, 고백 타이밍, 발전 가능성

#### 3. 이별 후 재회 희망자 (Reunion Seekers)
- **정의**: 이별 후 전 연인과의 재회를 원하는 상태
- **규모**: 전체의 약 12-15%
- **핵심 질문**:
  - "재회할 수 있을까?"
  - "언제쯤 연락이 올까?"
- **행동 패턴**: **극도로 높은 방문 빈도** (일 1-2회)
- **추천 콘텐츠**: 재회 가능성, 재회 시기, 상대방 현재 마음

#### 4. 관계 검증자 (Relationship Validators)
- **정의**: 현재 연애 중이거나 결혼을 고려하는 커플
- **규모**: 전체의 약 20-25%
- **핵심 질문**:
  - "이 사람이랑 정말 잘 맞나?"
  - "계속 함께해도 될까?"
  - "결혼해도 괜찮을까?"
- **행동 패턴**: 관계 전환점마다 방문
- **추천 콘텐츠**: 궁합 점수, 장기 관계 전망, 결혼 적합성

#### 5. 결혼 고민자 (Marriage Contemplators)
- **정의**: 결혼 적령기이나 아직 미혼인 상태
- **규모**: 전체의 약 15-20%
- **핵심 질문**:
  - "나도 결혼할 수 있을까?"
  - "언제 결혼하게 될까?"
- **행동 패턴**: 명절/가족모임 후 급증
- **추천 콘텐츠**: 결혼 시기, 결혼운, 배우자 특징

#### 6. 인생 역전 희망자 (Life Success Seekers)
- **정의**: 재물운과 성공운에 관심이 높은 전연령대
- **규모**: 전체의 약 15-20%
- **핵심 질문**:
  - "언제쯤 잘 되지?"
  - "내 팔자는 좋을까?"
- **행동 패턴**: 월초/월말 정기 체크
- **추천 콘텐츠**: 재물운, 투자 타이밍, 사업/이직 시기

### 통합 콘텐츠 전략

#### 시즌별 집중 전략
- **신년 (1-2월)**: 모든 세그먼트 대상 신년운세
- **봄 (3-5월)**: 새로운 인연, 짝사랑 집중
- **여름 (6-8월)**: 이별/재회, 관계 검증
- **가을 (9-11월)**: 결혼, 커플 궁합
- **연말 (12월)**: 인생 역전, 내년 계획

#### 세그먼트 간 이동 경로
```
새로운 인연 → 짝사랑 → 관계 검증 → 결혼 고민
                ↓
            이별 후 재회 → 새로운 인연 (순환)
```

#### 핵심 KPI
1. **짝사랑/이별 재회**: 방문 빈도 극대화 (일/주 단위 재방문)
2. **관계 검증/결혼**: 객단가 극대화 (프리미엄 콘텐츠)
3. **새로운 인연**: 신규 유입 극대화 (진입 장벽 낮춤)
4. **인생 역전**: 정기 구독 전환 (월간/연간)
